# Qazaq Daily

Минималистичный демо-сайт новостей на русском языке. Запуск: `npm start`, затем откройте `http://localhost:3000`. Другой порт можно задать переменной `PORT`.

Материалы сайта вымышлены. Новости находятся в `news.js`, а единственная настройка блокировки стран — `BLOCKED_COUNTRIES` в `config.js`.

## Географическое ограничение

Сервер проверяет страну до обработки любого маршрута, включая страницы, статические файлы и неизвестные адреса. Поддерживаются `request.geo.country`, `CF-IPCountry`, `x-vercel-ip-country` и `x-country-code`. Для `KG` возвращается страница 403 с предоставленной иллюстрацией `assets/region-blocked.jpg` и заголовками `no-store`; изображение встроено в страницу, поэтому оно остаётся видимым даже при блокировке всех отдельных URL. Неизвестная страна не блокируется.

Значения заголовков страны должны выставляться доверенным edge/reverse proxy, который определяет страну по IP и перезаписывает такие заголовки. Не публикуйте Node-сервер в обход этого proxy: IP-геолокацию нельзя достоверно определить по произвольному клиентскому заголовку. В production настройте proxy так, чтобы прямой доступ к origin был закрыт.

## Демонстрационные элементы

Курс валют, подписка, изображения и новости представлены как демонстрационные материалы. Форма подписки не отправляет и не сохраняет адрес.
